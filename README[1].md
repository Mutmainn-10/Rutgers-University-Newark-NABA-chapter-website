# NABA Rutgers–Newark Website

This folder is ready to upload to a GitHub repository.

## Files

- `index.html` — the complete website
- `rutgers-scarlet-knights-r.png` — transparent Rutgers Scarlet Knights “R” logo used on the site
- `naba-rutgers-newark-logo.png` — included NABA logo asset

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `naba-rutgers-newark`).
2. Upload every extracted file, including `index.html`, `rutgers-scarlet-knights-r.png`, `naba-rutgers-newark-logo.png`, and this README, to the repository's top-level folder.
3. In GitHub, open **Settings** → **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. GitHub will display your public website link after deployment.

The event editor and E-board editor save changes in the browser where they are made. For updates to appear for every visitor, edit the code or connect the site to a shared database later.
